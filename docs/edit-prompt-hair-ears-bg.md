# Промпт edit: крошки фона в волосах и ушах

> Проверено: 2026-08-08 · источники: сессия (прод `80.87.196.33`, пара `20260807T183951Z_i_8`)

## Вердикт

Усиление промптов в `EDIT_PROMPT` / `GOSUSLUGI_NANO_PROMPT` **даёт улучшение**: меньше кусков стены у ушей и меньше «сыра» в волосах. Идеала нет — у контура и в светлых прядях иногда остаются белые блики/дыры.

**С чего начать:** тексты в `backend/app/openrouter.py`; деплой API `80.87.196.33`. Текущий баланс: one-pass + правило «белый только снаружи силуэта».

**Дальше (не сейчас):** для **блондинок** текущий промпт всё ещё даёт белые блики/дыры в светлых прядях — нужен **другой подход** (отдельный промпт/постпроцесс/детект светлых волос), не добивать общий Gosuslugi-промпт. Пока оставляем как есть.

## Что сделали

| Изменение | Где | Статус |
|-----------|-----|--------|
| Проверка волос/ушей → убрать стену | `GOSUSLUGI_NANO_PROMPT` / `EDIT_PROMPT` | ✅ лучше |
| Белый `#FFFFFF` только **снаружи** силуэта; внутри массы — запрет дыр/«сыра»; светлые пряди = волосы | те же | ✅ лучше (блики ещё бывают) |
| Pass2 QC в API | `run_edit_nano_banana` | ❌ хуже у ушей, откат |

## Не брать / оговорки

- Промпт ≠ локальный bleach / matte.
- `/api/process/nano-banana` — **one-pass**. Pass2 не включать (дыры в ушах).
- Не путать блик на волосе с фоном: при сомнении оставлять волос.
