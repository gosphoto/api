# Post-crop cleanup раздувает лицо

> Проверено: 2026-08-29 · источники: прод `gosphoto-gate`, MediaPipe Face Mesh на in / crop(in) / out; повторный прогон IMG_4393 с `POST_CROP_CLEANUP_ENABLED=0`

## Вердикт

Второй вызов Gemini (`post_crop_cleanup` после кропа 35×45) **меняет пропорции лица**: овал ширина/высота растёт на **+3…+8%**, хотя промпт запрещает widen/stretch. Первый edit (пиджак + белый фон) овал почти не трогает. Кроп — один `scale`, без анаморфного сжатия; «крупнее в кадре» (`fillW`) — это норма паспорта, не баг формы.

**С чего начать:** держать `POST_CROP_CLEANUP_ENABLED=0` (дефолт кода, compose, `deploy.yml`). Не включать, пока нет замера, что oval_w/h после cleanup ≈ crop-only.

## Не брать / оговорки

- Не путать «лицо занимает больше кадра» (`fillW` 48% → ~59%) с «щёки шире черепа». Первое — `face_ratio=0.75` / ФМС 18–25 мм. Второе — oval_w/h.
- Пиджак сужает плечи → лицо кажется шире относительно торса даже при том же овале.
- `pipeline: local_person` в meta — баг имени: `cutout=openrouter_edit` не матчится на `riverflow`, хотя пиксели с Gemini.
- Существующие `results/` с applied cleanup не пересчитываются; кеш: `PROCESS_CACHE_VERSION=crop-width-corr-v1`.

## Кроп 3:4 → 35×45

Gemini отдаёт ~864×1184 (аспект 0.730), паспорт 827×1063 (0.778). Одинаковый `scale` по высоте головы, затем окно 35×45: **форма овала +0.2%**, но лицо занимает **+27% ширины кадра** (крупный план + более широкий кадр). `cv2.resize` патча не плющит (−0.1%).

`PASSPORT_CROP_WIDTH_CORR=auto` (дефолт): `crop_w *= (35/45) / (src_w/src_h)`, clip `[1, 1.12]`. На 3:4 это **~1.066** — чуть шире захват, при ресайзе в 35×45 лицо уже на ~6.6% (как если бы кадр остался 3:4). На входе уже 35×45 коэффициент = 1. Выключить: `PASSPORT_CROP_WIDTH_CORR=1`.

Это не отменяет укрупнение под `face_ratio=0.75` (норма 32–36 мм). Только аспект.

## Как включить обратно

`POST_CROP_CLEANUP_ENABLED=1` в `.env` + `deploy.yml` (сейчас деплой **перезаписывает** флаг). Перед этим: тот же замер oval_w/h на 5+ парах, Δ vs crop-only < 0.02.

Код пути (`_finalize_crop`, промпт, тесты с monkeypatch `True`) оставляем.
